Problema 02

Cuadrado Latino con Dato Faltante

01
Contexto de Experimento
Diseño Cuadrado Latino 4×4

📌 Enunciado: Un ingeniero industrial investiga el efecto de cuatro métodos de ensamblaje (A, B, C y D) sobre el tiempo de ensamblaje de un componente para televisores a color por parte de cuatro operadores (1, 2, 3 y 4). Debido a que el proceso genera fatiga, el orden cronológico del turno (Operador de Montaje: 1, 2, 3 y 4) influye de forma directa en el rendimiento. Durante las corridas, se extravió el tiempo de la Fila 3, Columna 3 (Método C). El experimento se registra bajo el siguiente cuadrado latino:

Operador de Montaje Operador 1 Operador 2 Operador 3 Operador 4
1C=10D=14A=7B=8
2B=7C=18D=11A=8
3A=5B=10C=YD=9
4D=10A=10B=12C=14

🎯 Objetivo general

Evaluar si existen diferencias estadísticamente significativas en el tiempo de armado debido a los métodos de ensamblaje (tratamiento), controlando la variabilidad de los operadores (bloque columna) y el efecto de fatiga por turno / operador de montaje (bloque fila) mediante un diseño de cuadrado latino 4×4 con estimación analítica por dato perdido.

🧪 Factores estudiados

  • Factor tratamiento (método de ensamblaje): 4 niveles (A, B, C, D).
  • Factor bloque fila (operador de montaje / orden temporal): 4 niveles (1, 2, 3, 4).
  • Factor bloque columna (operador individual): 4 niveles (1, 2, 3, 4).

Tratamiento:
Método de Ensamblaje		 H₀: τ₁ = τ₂ = τ₃ = τ₄ = 0
Todos los métodos de ensamblaje producen el mismo tiempo promedio.		 H₁: Al menos un τk ≠ 0
Por lo menos un método de ensamblaje genera un tiempo promedio diferente.
Bloque Fila:
Operador Montaje (Fatiga)		 H₀: α₁ = α₂ = α₃ = α₄ = 0
El orden cronológico del ensamblaje no tiene efecto en el tiempo medio.		 H₁: Al menos un αi ≠ 0
La fatiga incremental altera de forma significativa el tiempo de ensamblaje.
Bloque Columna:
Operador Individual		 H₀: β₁ = β₂ = β₃ = β₄ = 0
No existe variabilidad en el tiempo medio debido a la destreza de los operadores.		 H₁: Al menos un βj ≠ 0
Existen diferencias significativas en la velocidad promedio entre operadores.

# 1. CREACIÓN DEL DATA FRAME CON EL DATO ESTIMADO (Y = 13)
datos_dcl <- data.frame(
  Operador_Montaje = factor(rep(paste("Fila", 1:4), each = 4)),
  Operador         = factor(rep(paste("Op", 1:4), times = 4)),
  Metodo           = factor(c("C","D","A","B",
                              "B","C","D","A",
                              "A","B","C","D",
                              "D","A","B","C")),
  Tiempo           = c(10, 14,  7,  8,
                       7, 18, 11,  8,
                       5, 10, 13,  9,  # El valor 13 es el dato estimado (Y)
                       10, 10, 12, 14)
)

# 2. AJUSTE DEL MODELO LINEAL GENERAL
modelo <- lm(Tiempo ~ Operador_Montaje + Operador + Metodo, data = datos_dcl)
anova_estandar <- anova(modelo)

# 3. CORRECCIÓN ESTADÍSTICA DE GRADOS DE LIBERTAD POR DATO FALTANTE
anova_corregido <- anova_estandar

# Restar 1 grado de libertad al Error Residual
anova_corregido$Df[4] <- anova_estandar$Df[4] - 1 

# Recalcular Cuadrado Medio (MS) del Error
anova_corregido$`Mean Sq`[4] <- anova_corregido$`Sum Sq`[4] / anova_corregido$Df[4]

# Recalcular Estadísticos F0 para todos los factores usando el nuevo MS del error
anova_corregido$`F value`[1:3] <- anova_corregido$`Mean Sq`[1:3] / anova_corregido$`Mean Sq`[4]

# Recalcular Valores P reales con la distribución F_RT (grados de libertad corregidos)
anova_corregido$`Pr(>F)`[1:3] <- pf(anova_corregido$`F value`[1:3], 
                                    anova_corregido$Df[1:3], 
                                    anova_corregido$Df[4], 
                                    lower.tail = FALSE)

# 4. DESPLIEGUE DE LA TABLA ANOVA FINAL EN CONSOLA
cat("\n==================================================================\n")
cat(" TABLA ANOVA CORREGIDA (DISEÑO EN CUADRADO LATINO CON DATO PERDIDO)\n")
cat("==================================================================\n")
print(anova_corregido)
cat("==================================================================\n")
