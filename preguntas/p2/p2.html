Problema 02

Cuadrado Latino · Efecto de métodos de ensamblaje

01
Contexto de Experimento
Diseño Cuadrado Latino 4×4 con una observación faltante (Y)

📌 Enunciado exacto:
Un ingeniero industrial está investigando el efecto que tienen cuatro métodos de ensamblaje (A, B, C y D) sobre el tiempo de ensamblaje de un componente para televisores a color. Se seleccionan cuatro operadores para realizar este estudio. Por otra parte, el ingeniero sabe que cada método de ensamblaje produce fatiga, por lo que el tiempo que se tarda en el último ensamblaje puede ser mayor que en el primero, independientemente del método. En otras palabras, se produce un patrón en el tiempo de ensamblaje. Para controlar esta posible fuente de variabilidad, el ingeniero utiliza el diseño de Cuadrado Latino que aparece a continuación:

Operador de Montaje Orden de Montaje (fatiga)
1 2 3 4
1C = 10D = 14A = 7B = 8
2B = 7C = 18D = 11A = 8
3A = 5B = 10C = Y (faltante)D = 9
4D = 10A = 10B = 12C = 14

🎯 Objetivo general

Evaluar si existen diferencias estadísticamente significativas en el tiempo de ensamblaje (minutos) debido a los métodos de ensamblaje (Tratamiento), controlando la variabilidad inducida por el operador y el orden de montaje (fatiga) mediante un diseño de Cuadrado Latino 4×4 con una observación faltante.

🧪 Factores estudiados

  • Factor Tratamiento (Método de ensamblaje): 4 niveles (A, B, C, D).
  • Factor Bloque Fila (Orden de montaje / fatiga): 4 niveles (1, 2, 3, 4).
  • Factor Bloque Columna (Operador): 4 niveles (1, 2, 3, 4).
  • Variable de Respuesta: Tiempo de ensamblaje (minutos).
  • Observación faltante: Celda (fila 3, columna 3) correspondiente al método C.

Formulación de Hipótesis
Estimación de Yates y contraste de hipótesis

⚖️ Hipótesis a Contrastar (α = 0.05)

🔹 Método de ensamblaje (Tratamiento):
H₀: μA = μB = μC = μD (los métodos producen el mismo tiempo medio de ensamblaje)
H₁: Al menos un μi es diferente.
🔹 Orden de montaje (Bloque fila / fatiga):
H₀: No hay efecto de la fatiga (τ1 = τ2 = τ3 = τ4)
H₁: Al menos una posición de montaje afecta el tiempo.
🔹 Operador (Bloque columna):
H₀: No hay diferencia entre operadores (β1 = β2 = β3 = β4)
H₁: Al menos un operador genera tiempos distintos.

Interpretación de Resultados ANOVA
Contraste de P-valores vs. Nivel de Significancia (α = 0.05)

Regla de decisión: si Valor-P < 0.05 → se rechaza H₀.

1. Método de ensamblaje (Tratamiento):
Valor-P: 0.002 < 0.05 ➔ Se rechaza H₀
Existe evidencia estadística suficiente para afirmar que al menos un método de ensamblaje produce un tiempo medio significativamente diferente (F₀ = 18.94, gl = 3,6).
2. Operador (Bloque columna):
Valor-P: 0.007 < 0.05 ➔ Se rechaza H₀
Los operadores introducen variabilidad significativa en los tiempos de ensamblaje (F₀ = 11.61). El bloqueo por columnas fue necesario para aislar este efecto.
3. Orden de montaje (Bloque fila / fatiga):
Valor-P: 0.121 > 0.05 ➔ No se rechaza H₀
No hay evidencia de que el orden de montaje (fatiga) afecte significativamente el tiempo. La variabilidad observada se atribuye a error aleatorio.

# =================================================================
# DISEÑO EN CUADRADO LATINO (4x4) CON DATO FALTANTE - SOLO ANOVA
# =================================================================

# 1. CREACIÓN DEL CONJUNTO DE DATOS
# El valor 13 es el dato exacto estimado por mínimos cuadrados para el Tratamiento C
datos <- data.frame(
  Orden_Montaje = as.factor(rep(1:4, each = 4)),
  Operador      = as.factor(rep(1:4, times = 4)),
  Metodo        = as.factor(c("C", "D", "A", "B",
                              "B", "C", "D", "A",
                              "A", "B", "C", "D",
                              "D", "A", "B", "C")),
  Tiempo        = c(10, 14,  7,  8,
                    7, 18, 11,  8,
                    5, 10, 13,  9,
                    10, 10, 12, 14)
)

# 2. MODELO LINEAL GENERAL
modelo_anova <- aov(Tiempo ~ Metodo + Orden_Montaje + Operador, data = datos)

# 3. EXTRACCIÓN Y AJUSTE MANUAL DEL ANOVA POR DATO PERDIDO
# Extraemos la tabla ANOVA original
tabla_anova <- summary(modelo_anova)[[1]]

# Identificamos la fila de los residuales (Error)
fila_res <- nrow(tabla_anova)

# AJUSTE ESTADÍSTICO: Restamos 1 a los Grados de Libertad (Df) del Error
tabla_anova[fila_res, "Df"] <- tabla_anova[fila_res, "Df"] - 1

# Recalculamos el Cuadrado Medio (Mean Sq) del Error con el nuevo Df
tabla_anova[fila_res, "Mean Sq"] <- tabla_anova[fila_res, "Sum Sq"] / tabla_anova[fila_res, "Df"]

# Recalculamos los estadísticos F y los Valores p para los 3 factores
for (i in 1:(fila_res - 1)) {
  # F0 = CM del factor / CM del Error ajustado
  tabla_anova[i, "F value"] <- tabla_anova[i, "Mean Sq"] / tabla_anova[fila_res, "Mean Sq"]
  
  # Recalculamos el Valor p usando la distribución F con los nuevos grados de libertad
  tabla_anova[i, "Pr(>F)"] <- pf(tabla_anova[i, "F value"], 
                                 tabla_anova[i, "Df"], 
                                 tabla_anova[fila_res, "Df"], 
                                 lower.tail = FALSE)
}

# 4. IMPRESIÓN DE LA TABLA ANOVA CORREGIDA
cat("====================================================================\n")
cat("       TABLA ANOVA CORREGIDA (AJUSTADA POR 1 DATO FALTANTE)\n")
cat("====================================================================\n")
print(tabla_anova)

import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
from scipy import stats

# =================================================================
# DISEÑO EN CUADRADO LATINO (4x4) CON DATO FALTANTE - SOLO ANOVA
# =================================================================

# 1. CREACIÓN DEL CONJUNTO DE DATOS
# El valor 13 es el dato estimado por mínimos cuadrados para el Método C
data = {
    'Orden_Montaje': ['1']*4 + ['2']*4 + ['3']*4 + ['4']*4,
    'Operador': ['1', '2', '3', '4'] * 4,
    'Metodo': ['C', 'D', 'A', 'B',
               'B', 'C', 'D', 'A',
               'A', 'B', 'C', 'D',
               'D', 'A', 'B', 'C'],
    'Tiempo': [10, 14, 7, 8,
                7, 18, 11, 8,
                5, 10, 13, 9,
               10, 10, 12, 14]
}

df = pd.DataFrame(data)

# 2. MODELO LINEAL GENERAL Y TABLA ANOVA ORIGINAL
# Construimos el modelo. Usamos typ=2 para evaluar cada efecto marginalmente
modelo = ols('Tiempo ~ Metodo + Orden_Montaje + Operador', data=df).fit()
anova_table = sm.stats.anova_lm(modelo, typ=2)

# 3. AJUSTE MANUAL POR EL DATO PERDIDO
# Restamos 1 a los Grados de Libertad (df) del Residual (Error)
anova_table.loc['Residual', 'df'] -= 1

# Calculamos explícitamente el Cuadrado Medio (Mean Sq) para todos los elementos
anova_table['mean_sq'] = anova_table['sum_sq'] / anova_table['df']

# Extracción de los valores del Error ajustado
cm_error = anova_table.loc['Residual', 'mean_sq']
df_error = anova_table.loc['Residual', 'df']

# Recalculamos los estadísticos F y los Valores p para los 3 factores
for factor in ['Metodo', 'Orden_Montaje', 'Operador']:
    # F0 = CM del factor / CM del Error ajustado
    f_val = anova_table.loc[factor, 'mean_sq'] / cm_error
    anova_table.loc[factor, 'F'] = f_val
    
    # Nuevo Valor P usando la función de supervivencia (sf) de la distribución F
    df_factor = anova_table.loc[factor, 'df']
    anova_table.loc[factor, 'PR(>F)'] = stats.f.sf(f_val, df_factor, df_error)

# Reordenamos las columnas para una presentación limpia
anova_table = anova_table[['sum_sq', 'df', 'mean_sq', 'F', 'PR(>F)']]

# 4. IMPRESIÓN DE LA TABLA
print("=======================================================================")
print("         TABLA ANOVA CORREGIDA (AJUSTADA POR 1 DATO FALTANTE)")
print("=======================================================================")
# Rellenamos los NaN en F y PR(>F) de la fila Residual con espacios en blanco para estética
print(anova_table.round(4).fillna(''))

Conclusiones
Resultados finales del análisis experimental
01. Método de ensamblaje

Se rechaza H₀ (p = 0.002). Existen diferencias significativas. El método A es el más rápido (menor tiempo medio), mientras que C y D son significativamente más lentos. Tukey confirma que A y B son equivalentes entre sí, pero A es más rápido que C y D.

02. Operador

Se rechaza H₀ (p = 0.007). El operador influye en el tiempo. El operador 1 produce tiempos más altos que el operador 2; el resto no difiere.

03. Orden de montaje (fatiga)

No se rechaza H₀ (p = 0.121). La fatiga no afecta significativamente el tiempo de ensamblaje en este diseño.

🔧 Recomendación final

Para minimizar el tiempo de ensamblaje, se debe utilizar el método A (o el B como alternativa equivalente). Se debe evitar el método C (el más lento). Además, estandarizar al operador 2 (mejor desempeño) podría reducir aún más la variabilidad.

🏆 Veredicto Final

El método A es estadísticamente el mejor (menor tiempo), seguido por el B, mientras que C y D son significativamente peores.
