Problema 03

Cuadro Latino 4×4 – Valor faltante (Y)

01
Contexto de Experimento
Cuadrado Latino 4×4 – datos con una observación faltante (Y)

📌 Enunciado: Una empresa de marketing desea evaluar el impacto de diferentes estrategias publicitarias en las ventas de un producto durante cuatro semanas consecutivas en cuatro regiones distintas. El objetivo es determinar cuál estrategia genera las mayores ventas, mientras se controla el efecto de las regiones y las semanas como factores que podrían influir en los resultados.

El criterio de respuesta es el volumen de ventas (en miles de dólares) registrado al aplicar una estrategia específica en una región durante una semana. El diseño del Cuadrado Latino asegura que cada estrategia publicitaria se pruebe una vez en cada región y en cada semana. A continuación, se presenta el diseño experimental con un valor faltante (Y) en la celda correspondiente a la Semana 3, Región 3 (estrategia B):

Semana Región 1 Región 2 Región 3 Región 4
Semana 152 (B)60 (D)72 (A)58 (C)
Semana 256 (D)62 (B)65 (C)70 (A)
Semana 375 (A)72 (C)Y (B)66 (D)
Semana 464 (C)68 (A)61 (D)55 (B)

🎯 Objetivo general

Evaluar si existen diferencias estadísticamente significativas en las ventas (miles de $) causadas por la estrategia publicitaria (tratamiento), mientras se controla el efecto de bloque de regiones y semanas. Se identificará la estrategia óptima y se analizará el impacto del dato faltante en los grados de libertad.

🧪 Factores estudiados

  • Factor Tratamiento (Estrategia): 4 niveles (A, B, C, D).
  • Factor Bloque Fila (Semana): 4 niveles (Semana 1 a 4).
  • Factor Bloque Columna (Región): 4 niveles (Región 1 a 4).
  • Variable de Respuesta: Ventas (miles de dólares).
  • Dato faltante: Celda (Semana 3, Región 3) – estrategia B.
02
Formulación de Hipótesis
Estimación del valor faltante (Yates) y contrastes estadísticos

⚖️ Hipótesis a Contrastar (α = 0.05)

🔹 Estrategia publicitaria (Tratamiento):
H₀: μA = μB = μC = μD (no hay efecto de la estrategia)
H₁: Al menos una estrategia genera ventas medias diferentes.

Interpretación: evaluamos si el tipo de campaña publicitaria modifica las ventas.

🔹 Semana (bloque fila):
H₀: μSem1 = μSem2 = μSem3 = μSem4
H₁: Al menos una semana presenta ventas medias distintas.
🔹 Región (bloque columna):
H₀: μReg1 = μReg2 = μReg3 = μReg4
H₁: Al menos una región tiene ventas medias diferentes.
⚠️ Nota sobre grados de libertad: Debido al dato faltante, Minitab no reduce un grado de libertad adicional en el error (GLerror=6), mientras que Excel, R y Python aplican la corrección estándar perdiendo un GL (GLerror=5). Esto provoca diferencias en los p‑valores del factor Semana.

# -------------------------------------------------------------------------
# 1. ESPECIFICACIÓN DE LOS DATOS CONOCIDOS
# -------------------------------------------------------------------------
# Matriz de datos originales (Filas = Semanas, Columnas = Regiones)
# Se asigna temporalmente NA a la celda Y (Semana 3, Región 3)
matriz_datos <- matrix(c(
  52, 60, 72, 58,  # Semana 1
  56, 62, 65, 70,  # Semana 2
  75, 72, NA, 66,  # Semana 3
  64, 68, 61, 55   # Semana 4
), nrow = 4, byrow = TRUE)

# Matriz de Tratamientos (Estrategias Publicitarias)
matriz_trat <- matrix(c(
  "B", "D", "A", "C",
  "D", "B", "C", "A",
  "A", "C", "B", "D",
  "C", "A", "D", "B"
), nrow = 4, byrow = TRUE)

# -------------------------------------------------------------------------
# 2. ESTIMACIÓN ANALÍTICA DEL DATO PERDIDO (Y) POR MÍNIMOS CUADRADOS
# -------------------------------------------------------------------------
p <- 4 # Dimensión del cuadrado latino

# Totales marginales excluyendo la celda faltante (Semana 3, Región 3, Tratamiento B)
R3_prima <- sum(matriz_datos[3, ], na.rm = TRUE)                             # Fila 3
C3_prima <- sum(matriz_datos[, 3], na.rm = TRUE)                             # Columna 3
T_B_prima <- sum(matriz_datos[matriz_trat == "B"], na.rm = TRUE)             # Tratamiento B
G_prima   <- sum(matriz_datos, na.rm = TRUE)                                 # Gran Total

# Fórmula analítica exacta para Cuadrado Latino:
# Y = (p * (R_i' + C_j' + T_k') - 2 * G') / ((p - 1) * (p - 2))
Y_estimado <- (p * (R3_prima + C3_prima + T_B_prima) - 2 * G_prima) / ((p - 1) * (p - 2))

# Imprimir el valor calculado de Y
cat("Valor estimado analíticamente para Y:", round(Y_estimado, 4), "\n\n")

# Insertar el dato estimado en la matriz
matriz_datos[3, 3] <- Y_estimado

# -------------------------------------------------------------------------
# 3. REESTRUCTURACIÓN DE LOS DATOS PARA EL MODELO LINEAL
# -------------------------------------------------------------------------
df_experimento <- data.frame(
  Ventas     = as.vector(t(matriz_datos)),
  Semana     = factor(rep(paste0("Semana_", 1:4), each = 4)),
  Region     = factor(rep(paste0("Region_", 1:4), times = 4)),
  Estrategia = factor(as.vector(t(matriz_trat)))
)

# -------------------------------------------------------------------------
# 4. TABLA ANOVA CON AJUSTE DE GRADOS DE LIBERTAD (Dato Perdido)
# -------------------------------------------------------------------------
# Ajuste preliminar mediante modelo lineal estándar
modelo <- lm(Ventas ~ Semana + Region + Estrategia, data = df_experimento)
anova_inicial <- anova(modelo)

# Corrección estricta de Grados de Libertad (DF) por estimación de dato perdido
df_error_corregido <- anova_inicial["Residuals", "Df"] - 1  # 6 - 1 = 5
df_total_corregido <- sum(anova_inicial[, "Df"]) - 1       # 15 - 1 = 14

# Recálculo manual y preciso de la tabla ANOVA
ss_semana     <- anova_inicial["Semana", "Sum Sq"]
ss_region     <- anova_inicial["Region", "Sum Sq"]
ss_estrategia <- anova_inicial["Estrategia", "Sum Sq"]
ss_error      <- anova_inicial["Residuals", "Sum Sq"]
ss_total      <- sum(anova_inicial[, "Sum Sq"])

ms_semana     <- ss_semana / anova_inicial["Semana", "Df"]
ms_region     <- ss_region / anova_inicial["Region", "Df"]
ms_estrategia <- ss_estrategia / anova_inicial["Estrategia", "Df"]
ms_error      <- ss_error / df_error_corregido

F_semana     <- ms_semana / ms_error
F_region     <- ms_region / ms_error
F_estrategia <- ms_estrategia / ms_error

p_semana     <- pf(F_semana, anova_inicial["Semana", "Df"], df_error_corregido, lower.tail = FALSE)
p_region     <- pf(F_region, anova_inicial["Region", "Df"], df_error_corregido, lower.tail = FALSE)
p_estrategia <- pf(F_estrategia, anova_inicial["Estrategia", "Df"], df_error_corregido, lower.tail = FALSE)

# Construcción final del Data Frame de la ANOVA
tabla_anova <- data.frame(
  SS = c(ss_semana, ss_region, ss_estrategia, ss_error, ss_total),
  DF = c(anova_inicial["Semana", "Df"], anova_inicial["Region", "Df"], anova_inicial["Estrategia", "Df"], df_error_corregido, df_total_corregido),
  MS = c(ms_semana, ms_region, ms_estrategia, ms_error, NA),
  F0 = c(F_semana, F_region, F_estrategia, NA, NA),
  P_Value = c(p_semana, p_region, p_estrategia, NA, NA),
  row.names = c("Semanas (Filas)", "Regiones (Columnas)", "Estrategias (Tratamientos)", "Error", "Total")
)

cat("==================== TABLA ANOVA CORREGIDA ====================\n")
print(tabla_anova, na.print = "")
cat("\n")

# -------------------------------------------------------------------------
# 5. PRUEBA POST-HOC DE TUKEY EXHAUSTIVA Y DIAGNÓSTICO DINÁMICO
# -------------------------------------------------------------------------
# Valor crítico q de la tabla de rango studentizado (alfa = 0.05, k = 4, df_error = 5)
q_critico <- qtukey(p = 0.05, nmeans = p, df = df_error_corregido, lower.tail = FALSE)

# Límite Crítico HSD absoluto = q * sqrt(MS_error / p)
HSD <- q_critico * sqrt(ms_error / p)
cat("Valor Crítico q (0.05, 4, 5):", round(q_critico, 4), "\n")
cat("Límite Crítico HSD:", round(HSD, 4), "\n\n")

# Función interna para generar matrices combinatorias exhaustivas k*(k-1)/2
calcular_tukey_factor <- function(nombre_factor, datos_df) {
  cat(paste("--- Comparaciones Múltiples de Tukey para:", nombre_factor, "---\n"))
  
  # Cálculo de las medias de cada nivel del factor
  medias <- aggregate(Ventas ~ get(nombre_factor), data = datos_df, FUN = mean)
  colnames(medias) <- c("Nivel", "Media")
  
  pares <- combn(medias$Nivel, 2)
  tabla_comparaciones <- data.frame()
  
  for (i in 1:ncol(pares)) {
    p1 <- pares[1, i]
    p2 <- pares[2, i]
    
    m1 <- medias$Media[medias$Nivel == p1]
    m2 <- medias$Media[medias$Nivel == p2]
    
    dif_abs <- abs(m1 - m2)
    diagnostico <- ifelse(dif_abs > HSD, "SIGNIFICATIVO", "No Significativo")
    
    fila <- data.frame(
      Comparacion = paste(p1, "vs", p2),
      Dif_Absoluta = dif_abs,
      Diagnostico = diagnostico
    )
    tabla_comparaciones <- rbind(tabla_comparaciones, fila)
  }
  
  print(tabla_comparaciones, row.names = FALSE)
  cat("\n")
}

# Ejecución automatizada de Tukey para cada uno de los 3 factores
calcular_tukey_factor("Semana", df_experimento)
calcular_tukey_factor("Region", df_experimento)
calcular_tukey_factor("Estrategia", df_experimento)

import numpy as np
import pandas as pd
import scipy.stats as stats

# -------------------------------------------------------------------------
# 1. MATRIZ DE DATOS ORIGINALES (Filas = Semanas, Columnas = Regiones)
# -------------------------------------------------------------------------
# Se definen de forma explícita todos los valores numéricos del problema.
# La celda Y (Semana 3, Región 3) se inicializa temporalmente con np.nan.
datos_matriz = np.array([
    [52.0, 60.0, 72.0, 58.0],  # Semana 1
    [56.0, 62.0, 65.0, 70.0],  # Semana 2
    [75.0, 72.0, np.nan, 66.0], # Semana 3 (Faltante Y en la posición)
    [64.0, 68.0, 61.0, 55.0]   # Semana 4
], dtype=float)

# Matriz correspondiente a las Estrategias Publicitarias (Tratamientos)
trat_matriz = np.array([
    ["B", "D", "A", "C"],
    ["D", "B", "C", "A"],
    ["A", "C", "B", "D"],
    ["C", "A", "D", "B"]
])

p = 4  # Dimensión del Cuadrado Latino

# -------------------------------------------------------------------------
# 2. ESTIMACIÓN ANALÍTICA DEL DATO PERDIDO (Y) POR MÍNIMOS CUADRADOS
# -------------------------------------------------------------------------
# Se extraen los totales conocidos ignorando la celda con NaN
R3_prima = np.nansum(datos_matriz[2, :])                        # Fila de Y (Semana 3)
C3_prima = np.nansum(datos_matriz[:, 2])                        # Columna de Y (Región 3)
T_B_prima = np.nansum(datos_matriz[trat_matriz == "B"])          # Tratamiento de Y (Estrategia B)
G_prima = np.nansum(datos_matriz)                                # Gran Total provisional

# Fórmula analítica exacta por mínimos cuadrados para Cuadrado Latino: 
# Y = (p * (R_i' + C_j' + T_k') - 2 * G') / ((p - 1) * (p - 2))
Y_estimado = (p * (R3_prima + C3_prima + T_B_prima) - 2 * G_prima) / ((p - 1) * (p - 2))

print(f"--> Valor estimado analíticamente para Y: {Y_estimado:.4f}\n")

# Se introduce el valor calculado en la matriz de datos para procesar el ANOVA
datos_matriz[2, 2] = Y_estimado

# -------------------------------------------------------------------------
# 3. CÁLCULO DE LA TABLA ANOVA CORREGIDA (Dato Perdido)
# -------------------------------------------------------------------------
Suma_Total_G = np.sum(datos_matriz)
FC = (Suma_Total_G ** 2) / (p * p)  # Factor de corrección

SS_Total = np.sum(datos_matriz ** 2) - FC
SS_Semanas = (np.sum(np.sum(datos_matriz, axis=1) ** 2) / p) - FC
SS_Regiones = (np.sum(np.sum(datos_matriz, axis=0) ** 2) / p) - FC

# Sumas de cada tratamiento con la matriz rellenada
suma_A = np.sum(datos_matriz[trat_matriz == "A"])
suma_B = np.sum(datos_matriz[trat_matriz == "B"])
suma_C = np.sum(datos_matriz[trat_matriz == "C"])
suma_D = np.sum(datos_matriz[trat_matriz == "D"])

SS_Estrategias = ((suma_A**2 + suma_B**2 + suma_C**2 + suma_D**2) / p) - FC
SS_Error = SS_Total - SS_Semanas - SS_Regiones - SS_Estrategias

# Ajuste riguroso de Grados de Libertad (DF) por el dato estimado (-1 en Error y Total)
DF_Semanas = p - 1
DF_Regiones = p - 1
DF_Estrategias = p - 1
DF_Error = ((p - 1) * (p - 2)) - 1  # 6 - 1 = 5 grados de libertad corregidos
DF_Total = (p * p - 1) - 1          # 15 - 1 = 14 grados de libertad corregidos

# Cuadrados Medios (MS)
MS_Semanas = SS_Semanas / DF_Semanas
MS_Regiones = SS_Regiones / DF_Regiones
MS_Estrategias = SS_Estrategias / DF_Estrategias
MS_Error = SS_Error / DF_Error

# Estadísticos F0
F0_Semanas = MS_Semanas / MS_Error
F0_Regiones = MS_Regiones / MS_Error
F0_Estrategias = MS_Estrategias / MS_Error

# Valores P utilizando la distribución F (Survival Function)
P_Semanas = stats.f.sf(F0_Semanas, DF_Semanas, DF_Error)
P_Regiones = stats.f.sf(F0_Regiones, DF_Regiones, DF_Error)
P_Estrategias = stats.f.sf(F0_Estrategias, DF_Estrategias, DF_Error)

# -------------------------------------------------------------------------
# 4. FORMATEO Y DESPLIEGUE EN DATAFRAME DE PANDAS
# -------------------------------------------------------------------------
anova_dict = {
    "Fuente de Variación": [
        "Semanas (Filas)", 
        "Regiones (Columnas)", 
        "Estrategias (Tratamientos)", 
        "Error", 
        "Total"
    ],
    "SS (Suma Cuadrados)": [SS_Semanas, SS_Regiones, SS_Estrategias, SS_Error, SS_Total],
    "DF (Grados Libertad)": [DF_Semanas, DF_Regiones, DF_Estrategias, DF_Error, DF_Total],
    "MS (Cuadrados Medios)": [MS_Semanas, MS_Regiones, MS_Estrategias, MS_Error, np.nan],
    "F0 (Estadístico)": [F0_Semanas, F0_Regiones, F0_Estrategias, np.nan, np.nan],
    "P-Value": [P_Semanas, P_Regiones, P_Estrategias, np.nan, np.nan]
}

df_anova = pd.DataFrame(anova_dict).set_index("Fuente de Variación")

print("======================== TABLA ANOVA CORREGIDA ========================")
print(df_anova.to_string(na_rep=""))

Conclusiones
Recomendaciones finales y efectos del dato faltante
🎯 Estrategia publicitaria

Se rechaza H₀ (p ≈ 0.006–0.007). La estrategia A produce las ventas medias más altas y es significativamente mejor que B y D. La estrategia C es estadísticamente similar a A, aunque con menor media. No se recomienda B ni D.

📅 Semana y Región

El efecto semana es controversial (significativo solo tras corregir GL). Dado que el diseño controla este factor, la recomendación principal no se ve afectada. La región no influye en las ventas.

🧮 Lección sobre dato faltante

La diferencia en GL del error entre Minitab y los demás softwares demuestra la importancia de ajustar correctamente el análisis cuando existen observaciones perdidas. Excel, R y Python realizan la corrección adecuada, lo que se traduce en mayor potencia para detectar efectos de bloque.

🏆 Recomendación final

Implementar la estrategia A en todas las regiones, independientemente de la semana. Esta estrategia supera a B y D en ventas. Si el costo lo permite, puede considerarse también la estrategia C, aunque con evidencia menos concluyente de superioridad sobre A.
