🎯 Objetivo general

Determinar si existen diferencias significativas en el número de sacos defectuosos producidos en un día debido al tipo de máquina (Factor A), el operario (Factor B) y la posible interacción entre ambos factores (A×B).

🧪 Factores estudiados

  • Factor A (Máquina): 6 niveles (M1, M2, M3, M4, M5, M6).
  • Factor B (Hombre / Operario): 4 niveles (I, II, III, IV), correspondientes a 10, 15, 20 y 25 años de servicio.
  • Variable de respuesta: Número de sacos de harina de 25 kg que no cumplen con los estándares.
  • Repeticiones: 3 réplicas independientes por cada combinación de máquina y operario.
02
Formulación de Hipótesis
Pruebas Estadísticas (Descriptivas)

⚖️ Hipótesis para el Factor A (Máquina)

H₀ (Hipótesis Nula): El tipo de máquina procesadora no tiene un efecto significativo sobre la cantidad de sacos de harina defectuosos en un día. (Todas las máquinas producen, en promedio, la misma cantidad de defectos).

H₁ (Hipótesis Alternativa): Al menos un tipo de máquina procesadora tiene un efecto significativamente diferente sobre la cantidad de sacos de harina defectuosos en un día.

⚖️ Hipótesis para el Factor B (Hombre / Operario)

H₀ (Hipótesis Nula): El operario (sus años de servicio) no tiene un efecto significativo sobre la cantidad de sacos de harina defectuosos en un día.

H₁ (Hipótesis Alternativa): Al menos uno de los operarios tiene un efecto significativamente diferente sobre la cantidad de sacos de harina defectuosos en un día.

⚖️ Hipótesis para la Interacción (Máquina × Hombre)

H₀ (Hipótesis Nula): No existe un efecto de interacción significativo entre el tipo de máquina procesadora y el operario sobre la cantidad de sacos de harina defectuosos.

H₁ (Hipótesis Alternativa): Existe un efecto de interacción significativo entre el tipo de máquina procesadora y el operario sobre la cantidad de sacos de harina defectuosos.

04
Interpretación de Resultados ANOVA
¿Se aceptan o se rechazan las hipótesis?

Considerando un nivel de significancia del 5% (α = 0.05), se contrastan los p-valores obtenidos en la tabla ANOVA para tomar una decisión sobre las hipótesis planteadas:

1. Factor Tratamiento (Proveedor):
El p-valor es 0.007 < 0.05. Por lo tanto, se rechaza la hipótesis nula (H₀). Existe evidencia estadística empírica suficiente para afirmar que existen diferencias significativas en el peso medio del material dependiendo del proveedor suministrador.
2. Bloque Columna (Escala):
El p-valor es 0.015 < 0.05. En consecuencia, se rechaza la hipótesis nula (H₀). Las diferentes escalas empleadas en el experimento sí tienen un efecto significativo y generan variabilidad en la medición del peso. Aislar este bloque fue una decisión acertada para reducir el error experimental.
3. Bloque Fila (Inspector):
El p-valor es 0.216 > 0.05. En este caso, no se rechaza la hipótesis nula (H₀). No existe evidencia suficiente para afirmar que los diferentes inspectores influyan o generen un efecto estadísticamente significativo sobre el peso registrado.

# ==============================================================================
# 1. IMPORTAR LIBRERÍAS CLAVE
# ==============================================================================
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import statsmodels.api as sm
from statsmodels.formula.api import ols
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# ==============================================================================
# 2. CREACIÓN ESTRUCTURADA DE LOS DATOS (Diseño Cuadrado Latino)
# ==============================================================================
datos = pd.DataFrame({
    'Inspector': np.repeat(['I', 'II', 'III', 'IV'], 4),
    'Escala': np.tile(['1', '2', '3', '4'], 4),
    'Proveedor': ['A', 'B', 'C', 'D',
                  'B', 'C', 'D', 'A',
                  'C', 'D', 'A', 'B',
                  'D', 'A', 'B', 'C'],
    'Peso': [16, 10, 11, 13,
             15,  9, 14, 13,
             13, 12, 17, 14,
             16, 15, 13, 11]
})

for col in ['Inspector', 'Escala', 'Proveedor']:
    datos[col] = datos[col].astype('category')

# ==============================================================================
# 3. ANÁLISIS DE VARIANZA (ANOVA - Cuadrado Latino)
# ==============================================================================
modelo_latin = ols('Peso ~ C(Inspector) + C(Escala) + C(Proveedor)', data=datos).fit()
tabla_anova = sm.stats.anova_lm(modelo_latin, typ=1)

print("\n========================= TABLA ANOVA =========================")
print(tabla_anova)

# ==============================================================================
# 4. PRUEBA DE COMPARACIONES MÚLTIPLES DE TUKEY
# ==============================================================================
tukey = pairwise_tukeyhsd(endog=datos['Peso'], groups=datos['Proveedor'], alpha=0.05)
print("\n=================== PRUEBA DE TUKEY (IC) ===================")
print(tukey)

# ==============================================================================
# 5. VISUALIZACIÓN AVANZADA LADO A LADO
# ==============================================================================
fig, axes = plt.subplots(1, 2, figsize=(15, 6))
sns.set_theme(style="whitegrid")

tukey.plot_simultaneous(ax=axes[0], xlabel='Peso (g)')
axes[0].set_title('Gráfico de Tukey (Rangos de Comparación)\nIntervalos simultáneos', fontsize=13, fontweight='bold')
axes[0].set_ylabel('Proveedor')

sns.boxplot(ax=axes[1], data=datos, x='Proveedor', y='Peso', palette='mako', 
            hue='Proveedor', legend=False, boxprops=dict(alpha=0.7))
sns.stripplot(ax=axes[1], data=datos, x='Proveedor', y='Peso', color='black', alpha=0.5, size=6, jitter=0.1)

for i, prov in enumerate(['A', 'B', 'C', 'D']):
    max_y = datos[datos['Proveedor'] == prov]['Peso'].max()
    axes[1].text(i, max_y + 0.8, 'a', ha='center', va='bottom', fontsize=14, fontweight='bold', color='black')

axes[1].set_title('Distribución por Proveedor\nLetras iguales = sin diferencia significativa', fontsize=13, fontweight='bold')
axes[1].set_xlabel('Proveedor')
axes[1].set_ylabel('Peso (g)')

plt.tight_layout()
plt.show()

# 1. CARGAR LIBRERÍAS DE MANERA EFICIENTE ---------------------------------
if (!require("pacman")) install.packages("pacman")
pacman::p_load(tidyverse, agricolae, broom, patchwork)

# 2. CREACIÓN DE LOS DATOS (Vectorización limpia) -------------------------
datos <- data.frame(
  Inspector = factor(rep(c("I", "II", "III", "IV"), each = 4)),
  Escala    = factor(rep(1:4, times = 4)),
  Proveedor = factor(c("A", "B", "C", "D",
                       "B", "C", "D", "A",
                       "C", "D", "A", "B",
                       "D", "A", "B", "C")),
  Peso      = c(16, 10, 11, 13,
                15,  9, 14, 13,
                13, 12, 17, 14,
                16, 15, 13, 11)
)

# 3. ANÁLISIS DE VARIANZA (ANOVA - Cuadrado Latino) -----------------------
modelo_latin <- aov(Peso ~ Inspector + Escala + Proveedor, data = datos)
cat("\n========================= TABLA ANOVA =========================\n")
print(summary(modelo_latin))

# 4. PRUEBA DE TUKEY (Post-Hoc para Proveedor) ---------------------------
tukey_resultado <- TukeyHSD(modelo_latin, "Proveedor")
cat("\n=================== PRUEBA DE TUKEY (IC) ===================\n")
print(tukey_resultado)

# Grupos de Tukey para el gráfico de barras/cajas
tukey_grupos <- HSD.test(modelo_latin, "Proveedor", group = TRUE)

# 5. GENERACIÓN Y DESPLIEGUE DIRECTO EN RSTUDIO ---------------------------
# Gráfico 1: Intervalos de Confianza de Tukey
df_tukey <- as.data.frame(tukey_resultado$Proveedor) %>% 
  rownames_to_column(var = "Comparacion")

p1 <- ggplot(df_tukey, aes(x = reorder(Comparacion, diff), y = diff)) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "red", size = 0.8) +
  geom_errorbar(aes(ymin = lwr, ymax = upr), width = 0.2, color = "#2c3e50", size = 1) +
  geom_point(color = "#e74c3c", size = 3) +
  coord_flip() +
  labs(
    title = "Gráfico de Tukey (IC del 95%)",
    subtitle = "Comparación por parejas",
    x = "Comparación",
    y = "Diferencia media en Peso (g)"
  ) +
  theme_minimal(base_size = 11) +
  theme(plot.title = element_text(face = "bold"))

# Gráfico 2: Comportamiento por Proveedor + Letras de Tukey
df_grupos <- tukey_grupos$groups %>% 
  rownames_to_column(var = "Proveedor")

p2 <- ggplot(datos, aes(x = Proveedor, y = Peso, fill = Proveedor)) +
  geom_boxplot(alpha = 0.7, outlier.shape = NA, show.legend = FALSE) +
  geom_jitter(width = 0.1, size = 2, alpha = 0.5, show.legend = FALSE) +
  geom_text(data = df_grupos, aes(x = Proveedor, y = Peso + 1.5, label = groups), 
            fontface = "bold", size = 5, color = "black") +
  scale_fill_viridis_d(option = "mako") +
  labs(
    title = "Distribución por Proveedor",
    subtitle = "Letras iguales = sin diferencia significativa",
    x = "Proveedor",
    y = "Peso (g)"
  ) +
  theme_minimal(base_size = 11) +
  theme(plot.title = element_text(face = "bold"))

# Desplegar en la ventana 'Plots' de RStudio de forma inmediata
p1 + p2 + plot_layout(ncol = 2)
