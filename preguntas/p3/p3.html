Problema 02

Diseño Factorial · Máquina y Hombre en producción de sacos

01
Contexto de Experimento
Diseño Factorial 6×4 con tres réplicas

📌 Enunciado exacto:
Se desea estudiar el efecto que produce el factor A: máquina y el factor B: hombre, en la producción de sacos de harina premezclada para la elaboración de panes navideños de 25 kilogramos. Con este fin se empleó máquinas procesadoras de seis marcas diferentes y cuatro operarios con años de servicio distintos (10, 15, 20 y 25 años). En la tabla siguiente se han registrado los datos con repetición, del número de sacos de harina de 25 kilogramos, que no cumplen con los estándares establecidos por la gerencia de producción y calidad en la producción de un día.

🎯 Objetivo general

Evaluar si el tipo de máquina (6 niveles), el operario (4 niveles) y su interacción afectan significativamente el número de sacos defectuosos producidos por día, controlando la variabilidad mediante un diseño factorial completamente cruzado con tres repeticiones.

🧪 Factores estudiados

  • Factor A (Máquina): 6 niveles (M₁, M₂, M₃, M₄, M₅, M₆).
  • Factor B (Hombre / operario): 4 niveles (I, II, III, IV) según años de servicio.
  • Interacción A×B: Efecto conjunto de máquina y operario.
  • Variable de Respuesta: Número de sacos defectuosos (fuera de estándar) por día.
  • Diseño: Factorial 6×4 con 3 réplicas → 72 observaciones.
02
Formulación de Hipótesis
Planteamiento estadístico para efectos principales e interacción

⚖️ Hipótesis a Contrastar (α = 0.05)

🔹 Factor A (Máquina):
H₀: μM1 = μM2 = ... = μM6 (el tipo de máquina no influye en el número de defectuosos)
H₁: Al menos una máquina produce diferente cantidad de defectuosos.

Interpretación: Si la máquina no influyera, todas las marcas tendrían el mismo promedio de sacos defectuosos. La alternativa plantea que alguna máquina se comporta de manera distinta.

🔹 Factor B (Hombre / operario):
H₀: μI = μII = μIII = μIV (la experiencia del operario no afecta)
H₁: Al menos un operario genera distinto número de defectuosos.

Interpretación: La hipótesis nula supone que los años de servicio no influyen en la calidad; la alternativa indica que existe un efecto de la experiencia.

🔹 Interacción A×B:
H₀: No existe interacción entre máquina y operario (el efecto de la máquina es el mismo para todos los operarios)
H₁: Existe interacción significativa.

Interpretación: Si la interacción es significativa, la combinación específica de máquina y operario es importante, y el efecto de un factor depende del nivel del otro.

04
Interpretación de Resultados ANOVA
Contraste de P-valores vs. Nivel de Significancia (α = 0.05)

El análisis de varianza (ANOVA) evalúa la significancia estadística comparando el Valor-P calculado contra α = 0.05. Si Valor-P < α, se rechaza la hipótesis nula.

1. Factor Máquina (A):
Valor-P ≈ 0.000 < 0.05 ➔ Se rechaza H₀
El tipo de máquina influye significativamente en el número de sacos defectuosos (F₀ = 9.34, gl = 5,48). Existen diferencias entre al menos dos marcas.
2. Factor Hombre (B):
Valor-P ≈ 0.000 < 0.05 ➔ Se rechaza H₀
El operario afecta significativamente la producción de defectuosos (F₀ = 34.39, gl = 3,48). Los años de servicio influyen en el desempeño.
3. Interacción Máquina × Hombre:
Valor-P ≈ 0.000 < 0.05 ➔ Se rechaza H₀
Existe interacción significativa (F₀ = 4.29, gl = 15,48). El efecto de la máquina depende del operario que la utiliza, y viceversa. Esto implica que la combinación específica es crucial.

# 1. CREACIÓN DEL DATA FRAME CON LOS DATOS DE LA IMAGEN
datos <- data.frame(
  Maquina = factor(rep(paste0("M", 1:6), each = 3, times = 4)),
  Hombre  = factor(rep(c("I", "II", "III", "IV"), each = 18)),
  Sacos   = c(
    # Hombre I
    10,8,7,  12,13,15, 15,13,10, 8,5,6,  5,7,4,  5,6,3,
    # Hombre II
    5,6,8,   4,5,2,    6,6,5,   5,5,4,  5,4,4,  4,3,5,
    # Hombre III
    12,13,12,10,10,5,  9,6,4,   11,10,4,5,5,3,  8,3,6,
    # Hombre IV
    5,3,2,   2,3,4,    5,6,2,   5,4,1,  2,2,3,  2,4,1
  )
)

# 2. AJUSTE DEL MODELO LINEAL FACTORIAL CON INTERACCIÓN
modelo <- lm(Sacos ~ Maquina * Hombre, data = datos)

# 3. TABLA ANOVA COMPLETA
cat("--- TABLA ANOVA ---\n")
tabla_anova <- anova(modelo)
print(tabla_anova)

# 4. PRUEBA POST-HOC DE TUKEY EXHAUSTIVA
cat("\n--- PRUEBA DE COMPARACIONES MÚLTIPLES DE TUKEY ---\n")
prueba_tukey <- TukeyHSD(aov(modelo))

# Mostrar resultados individuales por factor
cat("\n[Tukey para Factor A: Maquina]\n")
print(prueba_tukey$Maquina)

cat("\n[Tukey para Factor B: Hombre]\n")
print(prueba_tukey$Hombre)

import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols

# 1. CREACIÓN DEL DATA FRAME CON LOS DATOS DE LA IMAGEN
# Definimos los factores repitiendo los niveles de forma cruzada para las 3 réplicas
maquina = []
for m in ["M1", "M2", "M3", "M4", "M5", "M6"]:
    maquina.extend([m] * 3)
maquina = maquina * 4

hombre = (
    ["I"] * 18 + ["II"] * 18 + ["III"] * 18 + ["IV"] * 18
)

sacos = [
    # Hombre I
    10, 8, 7,  12, 13, 15, 15, 13, 10, 8, 5, 6,  5, 7, 4,  5, 6, 3,
    # Hombre II
    5, 6, 8,   4, 5, 2,    6, 6, 5,   5, 5, 4,  5, 4, 4,  4, 3, 5,
    # Hombre III
    12, 13, 12,10, 10, 5,  9, 6, 4,   11, 10, 4,5, 5, 3,  8, 3, 6,
    # Hombre IV
    5, 3, 2,   2, 3, 4,    5, 6, 2,   5, 4, 1,  2, 2, 3,  2, 4, 1
]

df = pd.DataFrame({
    'Maquina': maquina,
    'Hombre': hombre,
    'Sacos': sacos
})

# 2. CONFIGURACIÓN Y AJUSTE DEL MODELO LINEAL (CON INTERACCIÓN)
modelo = ols('Sacos ~ C(Maquina) * C(Hombre)', data=df).fit()

# 3. GENERACIÓN DE LA TABLA ANOVA (Tipo II)
tabla_anova = sm.stats.anova_lm(modelo, typ=2)

print("=================================================================")
print("          TABLA ANOVA - DISEÑO FACTORIAL EN GOOGLE COLAB        ")
print("=================================================================\n")
print(tabla_anova.to_string())
print("\n=================================================================")

Conclusiones
Resultados finales del análisis experimental
01. Máquina

Se rechaza H₀ (p < 0.001). Las máquinas M₅ y M₆ producen significativamente menos sacos defectuosos que M₁, M₂, M₃ y M₄. No hay diferencias claras entre M₁, M₂, M₃ y M₄.

02. Hombre (experiencia)

Se rechaza H₀ (p < 0.001). El operario con 25 años (IV) es el que menos defectos genera, seguido del de 20 años (II). El operario con 10 años (I) es el peor. Existe una relación inversa entre experiencia y defectos.

03. Interacción

Se rechaza H₀ (p < 0.001). La combinación máquina-operario es crítica. Ciertas máquinas funcionan mejor con operarios experimentados, mientras que otras son más tolerantes.

🏭 Veredicto Final

Para minimizar los sacos defectuosos, se debe utilizar M₅ o M₆ y asignar al operario IV (25 años de experiencia). La combinación M₆ con operario IV es particularmente efectiva (media más baja). Evitar la combinación M₁ con operario I (peor resultado). Tanto la máquina como el operario influyen, y su interacción es determinante.
