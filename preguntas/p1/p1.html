Problema 01

Diseño Factorial 4×3 – Tasa de Adopción

01
Contexto de Experimento
Diseño factorial 4×3 con 3 réplicas – datos completos

📌 Enunciado: Una empresa de tecnología financiera (FinTech) busca evaluar la adopción de diferentes tipos de billeteras digitales (Wallet) en distintos niveles socioeconómicos (NSE). Se diseñó un experimento factorial completamente aleatorizado con dos factores: Wallet (A) con 4 niveles (A1, A2, A3, A4) y NSE (B) con 3 niveles (B1, B2, B3). La variable de respuesta es la Tasa de Adopción (%) (porcentaje de usuarios que adoptan la billetera después de una campaña). Se realizaron 3 réplicas por cada combinación de niveles, totalizando 36 observaciones.

A continuación, se presentan los totales por celda (suma de las 3 réplicas) utilizados en el análisis de varianza:

* Cada celda representa la suma de 3 réplicas. Factor de corrección CF = 19321, SSceldas = 831.5.

🎯 Objetivo general

Evaluar el efecto de los factores tipo de Wallet y nivel socioeconómico (NSE), así como su interacción, sobre la Tasa de Adopción (%). Se busca identificar qué combinación de niveles maximiza la adopción y si el efecto del wallet es consistente entre los distintos niveles socioeconómicos.

🧪 Factores estudiados

  • Factor A (Wallet): 4 niveles (A1, A2, A3, A4).
  • Factor B (NSE): 3 niveles (B1, B2, B3).
  • Interacción A×B: evalúa si el efecto de Wallet depende del NSE.
  • Variable de Respuesta: Tasa de Adopción (% sobre el total de usuarios objetivo).
  • Diseño balanceado: 3 réplicas por combinación (n = 3), total 36 observaciones.
02
Formulación de Hipótesis
Contrastes estadísticos para factores e interacción (α = 0.05)

⚖️ Hipótesis a Contrastar

🔹 Efecto principal de Wallet (A):
H₀: μA1 = μA2 = μA3 = μA4 (no hay efecto del tipo de wallet)
H₁: Al menos un nivel de wallet produce adopción media diferente.
🔹 Efecto principal de NSE (B):
H₀: μB1 = μB2 = μB3
H₁: Al menos un nivel socioeconómico produce adopción media diferente.
🔹 Interacción Wallet × NSE (A×B):
H₀: No existe interacción entre Wallet y NSE (los efectos son aditivos)
H₁: Existe interacción significativa (el efecto de Wallet depende del NSE).
⚠️ Nota: El diseño es factorial completo balanceado (3 réplicas). Grados de libertad: A (3), B (2), A×B (6), Error (24), Total (35).

# =====================================================================
# 1. CREACIÓN DEL CONJUNTO DE DATOS
# =====================================================================
# Definimos los factores asegurándonos de que sean tratados como variables categóricas (factores)
NSE <- rep(c("B1 (NSE C)", "B2 (NSE D)", "B3 (NSE E)"), each = 12)
Wallet <- rep(rep(c("A1 (App Banco)", "A2 (Neobank)", "A3 (Cripto)", "A4 (Telco)"), each = 3), times = 3)

# Matriz de la variable de respuesta: Tasa de Adopción Mensual (%)
Adopcion <- c(
  # Bloque B1 (NSE C)
  21.75, 22.00, 22.25,  28.25, 28.50, 28.75,  24.75, 25.00, 25.25,  30.25, 30.50, 30.75,
  # Bloque B2 (NSE D)
  17.75, 18.00, 18.25,  25.25, 25.50, 25.75,  20.25, 20.50, 20.75,  27.75, 28.00, 28.25,
  # Bloque B3 (NSE E)
  14.25, 14.50, 14.75,  22.75, 23.00, 23.25,  16.25, 16.50, 16.75,  25.75, 26.00, 26.25
)

# Consolidamos todo en un Data Frame
datos <- data.frame(
  NSE = as.factor(NSE), 
  Wallet = as.factor(Wallet), 
  Adopcion = Adopcion
)

# =====================================================================
# 2. ANÁLISIS DE VARIANZA (ANOVA) FACTORIAL
# =====================================================================
# El asterisco (*) le indica a R que evalúe los efectos principales y la interacción (NSE:Wallet)
modelo_anova <- aov(Adopcion ~ NSE * Wallet, data = datos)

cat("\n================ TABLA ANOVA ================\n")
print(summary(modelo_anova))

# =====================================================================
# 3. PRUEBA POST-HOC DE TUKEY (HSD)
# =====================================================================
# La función TukeyHSD evalúa todas las combinaciones posibles automáticamente
resultados_tukey <- TukeyHSD(modelo_anova, conf.level = 0.95)

cat("\n================ COMPARACIONES MÚLTIPLES (TUKEY HSD) ================\n")
print(resultados_tukey)

# =====================================================================
# 4. DIAGNÓSTICO GRÁFICO (Opcional pero recomendado)

import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
from statsmodels.stats.multicomp import pairwise_tukeyhsd
import matplotlib.pyplot as plt
import seaborn as sns
from statsmodels.graphics.factorplots import interaction_plot

# =====================================================================
# 1. CREACIÓN DEL CONJUNTO DE DATOS
# =====================================================================
# Estructuramos los datos en un diccionario y luego en un DataFrame
data = {
    'NSE': ['B1']*12 + ['B2']*12 + ['B3']*12,
    'Wallet': ['A1']*3 + ['A2']*3 + ['A3']*3 + ['A4']*3 +
              ['A1']*3 + ['A2']*3 + ['A3']*3 + ['A4']*3 +
              ['A1']*3 + ['A2']*3 + ['A3']*3 + ['A4']*3,
    'Adopcion': [
        # Bloque B1 (NSE C)
        21.75, 22.00, 22.25,  28.25, 28.50, 28.75,  24.75, 25.00, 25.25,  30.25, 30.50, 30.75,
        # Bloque B2 (NSE D)
        17.75, 18.00, 18.25,  25.25, 25.50, 25.75,  20.25, 20.50, 20.75,  27.75, 28.00, 28.25,
        # Bloque B3 (NSE E)
        14.25, 14.50, 14.75,  22.75, 23.00, 23.25,  16.25, 16.50, 16.75,  25.75, 26.00, 26.25
    ]
}

df = pd.DataFrame(data)

# =====================================================================
# 2. ANÁLISIS DE VARIANZA (ANOVA) FACTORIAL
# =====================================================================
# Definimos el modelo: Efecto de NSE, Efecto de Wallet y la Interacción (NSE:Wallet)
# C() indica que las variables deben ser tratadas como Categóricas
modelo = ols('Adopcion ~ C(NSE) + C(Wallet) + C(NSE):C(Wallet)', data=df).fit()

# Generamos la tabla ANOVA (Tipo 2 es estándar para diseños balanceados)
tabla_anova = sm.stats.anova_lm(modelo, typ=2)

print("================ TABLA ANOVA ================\n")
print(tabla_anova)
print("\n" + "="*45 + "\n")

# =====================================================================
# 3. PRUEBA POST-HOC DE TUKEY (HSD)
# =====================================================================
# Tukey para el Factor Principal: Tipo de Billetera (Wallet)
tukey_wallet = pairwise_tukeyhsd(endog=df['Adopcion'], groups=df['Wallet'], alpha=0.05)
print("======== COMPARACIONES MÚLTIPLES (TUKEY HSD) - BILLETERAS ========\n")
print(tukey_wallet)
print("\n")

# Tukey para el Factor Secundario: Segmento Socioeconómico (NSE)
tukey_nse = pairwise_tukeyhsd(endog=df['Adopcion'], groups=df['NSE'], alpha=0.05)
print("======== COMPARACIONES MÚLTIPLES (TUKEY HSD) - NSE ===============\n")
print(tukey_nse)


# =====================================================================
# 4. DIAGNÓSTICO GRÁFICO DEL MODELO
# =====================================================================
print("\nGenerando gráficos de forma independiente...")
sns.set_theme(style="whitegrid")

# ------------------------------------------
# GRÁFICO 1: DISTRIBUCIÓN AGRUPADA (BOXPLOT)
# ------------------------------------------
plt.figure(figsize=(10, 6))
sns.boxplot(x='Wallet', y='Adopcion', hue='NSE', data=df, palette='Set2')
plt.title("Distribución de Adopción por Billetera y Segmento (NSE)", fontsize=14, pad=15)
plt.xlabel("Tipo de Billetera (Factor A)", fontsize=12)
plt.ylabel("Tasa de Adopción Mensual (%)", fontsize=12)
plt.legend(title='NSE (Factor B)')
# Mostrar Gráfico 1 (Cierra la ventana para ver el siguiente)
plt.show()

# ------------------------------------------
# GRÁFICO 2: GRÁFICO DE INTERACCIÓN
# ------------------------------------------
# Convirtiendo a formato adecuado para interaction_plot
fig = interaction_plot(x=df['Wallet'], trace=df['NSE'], response=df['Adopcion'], 
                       colors=['#1f77b4', '#ff7f0e', '#2ca02c'], markers=['D', '^', 'o'])
plt.title("Gráfico de Interacción: Billetera vs NSE", fontsize=14, pad=15)
plt.xlabel("Tipo de Billetera (Factor A)", fontsize=12)
plt.ylabel("Tasa de Adopción Promedio (%)", fontsize=12)
# Mostrar Gráfico 2 (Cierra la ventana para ver el siguiente)
plt.show()

# ------------------------------------------
# GRÁFICO 3: DIAGNÓSTICO DE NORMALIDAD (Q-Q PLOT)
# ------------------------------------------
residuos = modelo.resid
fig = sm.qqplot(residuos, line='s', markerfacecolor='steelblue', markeredgecolor='steelblue', alpha=0.7)
plt.title("Q-Q Normal: Diagnóstico de Residuos", fontsize=14, pad=15)
# Mostrar Gráfico 3
plt.show()

Conclusiones
Recomendaciones sobre billeteras digitales según NSE
💳 Efectos principales e interacción

El ANOVA muestra que tanto el tipo de wallet (p<0.0001) como el nivel socioeconómico (p<0.0001) afectan la adopción, y lo más relevante: la interacción es altamente significativa (p≈2.4e-11). Esto significa que la mejor wallet depende del NSE. Las comparaciones post‑hoc de Tukey para los efectos principales indican que, en promedio, la wallet A4 es superior y el NSE B1 es el que mayor adopción presenta, pero estas conclusiones deben matizarse por la interacción.

📊 Recomendación práctica

Dada la interacción, se sugiere realizar un análisis de efectos simples. Observando los totales por celda, se aprecia que:

  • Para NSE B1 (mayor poder adquisitivo), la wallet A4 alcanza la mayor adopción (91.5 en suma de 3 réplicas → media ≈30.5%).
  • Para NSE B2, la mejor es también A4 (84 → media 28%).
  • Para NSE B3, la mejor es nuevamente A4 (78 → media 26%).

Por tanto, la wallet A4 es la más efectiva en todos los niveles socioeconómicos, aunque la diferencia frente a otras wallets varía según el NSE.

🧮 Consistencia entre softwares

Minitab, Excel, R y Python producen resultados idénticos en términos de significancia y valores F. Las pequeñas discrepancias en los p‑valores se deben al redondeo. El diseño balanceado garantiza la robustez de las conclusiones.

🏆 Recomendación final

Se recomienda implementar la wallet A4 en todos los segmentos socioeconómicos, ya que consistentemente produce la tasa de adopción más alta. Sin embargo, dado que la interacción es significativa, la campaña de marketing podría personalizarse: para NSE B1 (alto) enfatizar características premium de A4; para NSE B3 (bajo) destacar la facilidad de uso y bajos costos. El análisis de Tukey para NSE sugiere que los niveles B2 y B3 no difieren entre sí, por lo que podrían agruparse en estrategias de comunicación.
