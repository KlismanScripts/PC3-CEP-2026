Problema 04

Cuadro Latino 4×4 – Resistencia del tejido

01
Contexto de Experimento
Cuadrado Latino 4×4 – datos completos sin valor faltante

📌 Enunciado: Una empresa fabricante de ropa deportiva quiere evaluar la calidad del suministro de diferentes proveedores de tela. Para este propósito, se diseña un experimento con el objetivo de identificar si hay diferencias significativas en la resistencia del tejido producido por cuatro proveedores (A, B, C, D). El criterio de respuesta es la resistencia promedio del tejido (en unidades de fuerza) obtenida al realizar las pruebas en las máquinas. Se utiliza un diseño de Cuadrado Latino (4×4), donde cada proveedor aparece una vez en cada fila (día de prueba) y cada columna (máquina).

A continuación, se presenta la tabla de datos original del experimento:

Día / Máquina Máquina 1 Máquina 2 Máquina 3 Máquina 4
Día 1118 (B)136 (D)168 (A)135 (C)
Día 2127 (D)141 (B)129 (C)151 (A)
Día 3174 (A)173 (C)126 (B)134 (D)
Día 4130 (C)170 (A)125 (D)95 (B)

🎯 Objetivo general

Evaluar si existen diferencias estadísticamente significativas en la resistencia del tejido (unidades) causadas por el proveedor (tratamiento), mientras se controla el efecto de bloque de días de prueba y máquinas. Se identificará el proveedor que ofrece la mayor resistencia y se analizará la consistencia del experimento.

🧪 Factores estudiados

  • Factor Tratamiento (Proveedor): 4 niveles (A, B, C, D).
  • Factor Bloque Fila (Día de prueba): 4 niveles (Día 1 a 4).
  • Factor Bloque Columna (Máquina): 4 niveles (Máquina 1 a 4).
  • Variable de Respuesta: Resistencia del tejido (unidades de fuerza).
  • Diseño balanceado: No hay datos faltantes, el cuadrado es completo.
02
Formulación de Hipótesis
Contrastes estadísticos para cada factor (α = 0.05)

⚖️ Hipótesis a Contrastar

🔹 Proveedor (Tratamiento):
H₀: μA = μB = μC = μD (no hay efecto del proveedor)
H₁: Al menos un proveedor genera resistencia media diferente.

Interpretación: evaluamos si el origen del tejido influye en la resistencia.

🔹 Día (bloque fila):
H₀: μDía1 = μDía2 = μDía3 = μDía4
H₁: Al menos un día presenta resistencia media distinta.
🔹 Máquina (bloque columna):
H₀: μMáq1 = μMáq2 = μMáq3 = μMáq4
H₁: Al menos una máquina produce resistencia media diferente.
⚠️ Nota: El diseño es un cuadrado latino completo (sin datos faltantes). Todos los softwares reportan los mismos grados de libertad: GLError = (4-1)(4-2) = 6, GLTotal = 15.

🔹 Día (Bloque fila):

# ==========================================
# 1. MATRIZ DE DATOS
# ==========================================
# Definir los valores leídos por filas (Día 1 al Día 4)
valores <- c(118, 136, 168, 135,
             127, 141, 129, 151,
             174, 173, 126, 134,
             130, 170, 125, 95)

# Crear los factores correspondientes
filas <- as.factor(rep(c("Día 1", "Día 2", "Día 3", "Día 4"), each = 4))
columnas <- as.factor(rep(c("Máquina 1", "Máquina 2", "Máquina 3", "Máquina 4"), times = 4))
tratamientos <- as.factor(c("B", "D", "A", "C",
                            "D", "B", "C", "A",
                            "A", "C", "B", "D",
                            "C", "A", "D", "B"))

# Construir el Data Frame
df <- data.frame(Fila = filas, Columna = columnas, Tratamiento = tratamientos, Valor = valores)

# ==========================================
# 2. ANÁLISIS ANOVA
# ==========================================
# Modelo del Diseño en Cuadrado Latino
modelo_dcl <- aov(Valor ~ Tratamiento + Fila + Columna, data = df)

cat("=== TABLA ANOVA ===\n")
print(summary(modelo_dcl))

# ==========================================
# 3. PRUEBAS DE TUKEY (Post-Hoc)
# ==========================================
# Ejecutar Tukey para todos los factores del modelo con un alfa = 0.05
tukey_resultados <- TukeyHSD(modelo_dcl, conf.level = 0.95)

cat("\n=== COMPARACIONES MÚLTIPLES DE TUKEY ===\n")
print(tukey_resultados)

import pandas as pd
import statsmodels.api as sm
from statsmodels.formula.api import ols
from statsmodels.stats.multicomp import pairwise_tukeyhsd

# ==========================================
# 1. MATRIZ DE DATOS Y CONSTRUCCIÓN DEL DATAFRAME
# ==========================================
# Estructuramos los datos fila por fila (de izquierda a derecha y de arriba a abajo)
datos = {
    'Dia': ['Dia 1']*4 + ['Dia 2']*4 + ['Dia 3']*4 + ['Dia 4']*4,
    'Maquina': ['Maq 1', 'Maq 2', 'Maq 3', 'Maq 4'] * 4,
    'Proveedor': ['B', 'D', 'A', 'C',
                  'D', 'B', 'C', 'A',
                  'A', 'C', 'B', 'D',
                  'C', 'A', 'D', 'B'],
    'Resistencia': [118, 136, 168, 135,
                    127, 141, 129, 151,
                    174, 173, 126, 134,
                    130, 170, 125, 95]
}

# Convertimos el diccionario a un DataFrame de Pandas
df = pd.DataFrame(datos)

# ==========================================
# 2. CÁLCULO DE LA TABLA ANOVA
# ==========================================
# Usamos C() en la fórmula para forzar a statsmodels a tratar las variables como categóricas.
modelo_dcl = ols('Resistencia ~ C(Proveedor) + C(Dia) + C(Maquina)', data=df).fit()

# Calculamos el ANOVA Tipo II
tabla_anova = sm.stats.anova_lm(modelo_dcl, typ=2)

print("="*60)
print(" TABLA ANOVA - DISEÑO EN CUADRADO LATINO (4x4)")
print("="*60)
print(tabla_anova)
print("\n")

# ==========================================
# 3. PRUEBAS DE COMPARACIONES MÚLTIPLES (TUKEY HSD)
# ==========================================
# Nivel de significancia
alfa = 0.05

print("="*60)
print(" 1. PRUEBA DE TUKEY: PROVEEDORES (Tratamientos)")
print("="*60)
tukey_proveedor = pairwise_tukeyhsd(endog=df['Resistencia'], groups=df['Proveedor'], alpha=alfa)
print(tukey_proveedor)
print("\n")

print("="*60)
print(" 2. PRUEBA DE TUKEY: DÍAS (Filas)")
print("="*60)
tukey_dia = pairwise_tukeyhsd(endog=df['Resistencia'], groups=df['Dia'], alpha=alfa)
print(tukey_dia)
print("\n")

print("="*60)
print(" 3. PRUEBA DE TUKEY: MÁQUINAS (Columnas)")
print("="*60)
tukey_maquina = pairwise_tukeyhsd(endog=df['Resistencia'], groups=df['Maquina'], alpha=alfa)
print(tukey_maquina)

Conclusiones
Recomendaciones finales sobre proveedores de tela
🎯 Proveedor

Se rechaza H₀ (p ≈ 0.00085). El proveedor A produce la resistencia media más alta (165.75 unidades) y es significativamente superior a B, C y D. No hay diferencias significativas entre C y D, ni entre B y D, pero B es inferior a C. La jerarquía: A > C ≈ D > B.

📅 Día y Máquina

Ambos factores de bloque resultaron significativos (p = 0.039 y p = 0.016, respectivamente). Esto confirma que controlar el día de medición y la máquina fue crucial para reducir la variabilidad y aislar el efecto del proveedor.

🧮 Consistencia entre softwares

Minitab, Excel, R y Python arrojan resultados prácticamente idénticos. La ausencia de datos faltantes garantiza grados de libertad uniformes y conclusiones robustas.

🏆 Recomendación final

Se debe seleccionar al Proveedor A como único suministrador de tela, ya que ofrece la mayor resistencia del tejido. Los proveedores C y D son equivalentes entre sí pero inferiores a A. El proveedor B es el menos recomendable. El diseño experimental fue adecuado para controlar las fuentes de variabilidad (día y máquina).
